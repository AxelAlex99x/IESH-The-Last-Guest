# The Last Guest: A-Frame 360° scene

IESH Assignment 2: an interactive 360° panorama story built with A-Frame.

## Story
You wake in a guest room at Mistvale Lodge. The host has left before dawn,
and the garden door is locked. Its code is the year the house was built,
and the four digits are hidden around the house. Find them, unlock the
door, and step outside to the breakfast waiting on the terrace.

## How to play
1. Click the note on the dressing table to read it.
2. Find the four glowing digits: by the clock and at the mirror (bedroom),
   at the piano and by the stove (lounge).
3. Use the arrow on the bedroom door to go to the lounge.
4. Click the red box next to the dark wooden door and enter the code.
5. Step out onto the terrace.

## Features
- 3 panoramas (bedroom, lounge, terrace) with clickable navigation
- Text placed over specific parts of each panorama
- Transparent PNGs: note, arrows, birds
- Shapes and lines: rings, keypad box and buttons, door outline (lines),
  mist sphere, breakfast built from primitives
- Animations: pulsing digits, hover effects, lifting mist, flying birds,
  finale text, breakfast appearing, rising steam
- Interactive numeric keypad with code check (red WRONG / green OPEN)
